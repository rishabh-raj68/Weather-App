# 🌤️ Weather App

A simple and responsive **Weather App** built using **HTML, CSS, and JavaScript**. The application uses a **Weather API** to fetch and display real-time weather information for a searched location.

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Display current temperature
* ☁️ Show weather condition
* 💧 Display humidity
* 💨 Show wind speed
* 📍 Display location details
* ⚡ Fetch real-time weather data using an API
* 📱 Responsive design for different screen sizes
* ❌ Handles invalid or unavailable locations

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and API handling
* **Weather API** – Fetching real-time weather data
* **Fetch API** – Making API requests

## 🔄 How It Works

1. Enter a city name in the search box.
2. JavaScript sends a request to the Weather API.
3. The API returns the weather data in JSON format.
4. JavaScript processes the response.
5. The weather information is dynamically displayed on the webpage.
